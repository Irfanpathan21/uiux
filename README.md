# UI/UX Lab Practicals (1 to 7)

Comprehensive, exam-ready, and verified practical implementations for UI/UX Laboratory Examination.

📦 **Direct Download**: [Download devuiux.zip](https://github.com/Irfanpathan21/uiux/releases/download/v1.0.0/devuiux.zip)

---

## 🚀 Quick Start

1. Download and extract **`devuiux.zip`** (or clone this repository).
2. Double-click **`run.bat`** (or **`run_practicals.bat`**).
3. The interactive console launcher detects your environment, automatically handles dependency installation via `npm install` when needed, and opens each practical directly in your browser.

## ⚡ Key Highlights
- **100% Offline Capability**: Offline React, Babel, and Angular libraries are included in `lib/` so everything works in college labs without internet.
- **Zero-Config Browser Run**: Double-clicking `index.html` immediately runs any frontend practical in Chrome, Edge, or Firefox.
- **Auto-Dependency Installation**: The batch runner checks for Node/npm and automatically installs missing `node_modules` if you choose to run via Vite / Node CLI.
